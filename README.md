# Evangelys

Site vitrine d'Evangelys (evangelys.fr) : Vierges de Lourdes, Vierges Miraculeuses, Sainte Famille et crèche de Noël imprimées à la pièce.

Site statique publié avec GitHub Pages.

- `index.html` : la page, avec la liste des modèles, couleurs, tailles et prix dans le script en bas (`MODELS`, `STD`).
- `STRIPE` (en haut du script) : lien de paiement de chaque modèle. Vide = le bouton mène au formulaire de commande par e-mail.
- `cut/` : photos détourées, toutes au même format (900 × 1200, fond transparent).
- `partage.jpg` : image d'aperçu quand le lien est partagé sur les réseaux.
- `CNAME` : relie le site au domaine evangelys.fr.
